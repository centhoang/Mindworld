# Docs index

Each doc has one job. Keep each under 80 lines. Old detail lives in `archive/`: grep it, never read it whole.

| Doc | Job |
|---|---|
| `RESTRUCTURE.md` | The plan for this rework: scopes, order, open decisions |
| `BUGS.md` | Open bugs, by scope |
| `game/design.md` | What the game is: pitch, loop, systems, what is in or out |
| `game/implementation.md` | How the game is built: modules, data, rules. No visuals |
| `ai/npc.md` | Villager minds and chat |
| `ai/pet.md` | Pet minds, Teach and Prove |
| `ai/models.md` | Models, training, numbers, spend |
| `visual/visual.md` | Visual scope: what must be drawn, and the look decision |
| `visual/layers.md`, `tile-rules.md`, `style.md` | Current pixel rules. Rewritten or dropped after the look decision |
| `network/network.md` | Sync, AOI, capacity |
| `testing/testing.md` | Labs, checklists and the review loop |
| `testing/checks/*.md` | One short checklist per scope |
| `ops/` | Event rules, deploy, credits, demo script, drafts, Director mode |
| `archive/` | Superseded plans and full history |
