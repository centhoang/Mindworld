## Fixes (code)
- Greetings to a player ask Muse Spark first (`NpcVillage.speak`), with the talk so far; local 1B only when the cloud gives nothing.
- Cloud notes start with the time of day and what the villager is doing (`nowText`); oldest talk dropped to fit 1400 chars.
- Lines a villager tells a player (pitch, grudge, greeting) join that player's talk, so the next reply knows them.
- No greeting while a player is mid-talk; a grudge is never raised again once the talk already holds it.
- `VILLAGER_STYLE`: fit the time, never speak of yourself by name, no correcting small talk. "Speak first" prompt for greetings.
- `parseOffer`: "sell (it to) you", "want to sell" is a sell.
- Per-client chat cap removed (`CHAT_QUOTA`), `perClient` optional in the ledger.
